# Provenance and attribution

All source code in this repository was written by the authors. No third-party
source code, publisher PDF, or external asset is redistributed here.

The comparison methods are the authors' **own reimplementations** of published
algorithms, all driven through one shared interface by
`experiments/run_main_sweep.py`. The original publications are cited in the
manuscript and listed below for orientation; the manuscript's reference list
carries the full bibliographic details.

| Module | Method | Original publication |
|---|---|---|
| `baselines/HERO.py` | HERO | Mi et al. (2011) |
| `baselines/SIDR.py` | SIDR | Chen et al. (2020) |
| `baselines/Centering.py` | global-position centring rule | specification in the manuscript's Methods |
| `baselines/CR_MGC.py` | CR-MGC, graph-optimisation-style recovery | specification in the manuscript's Methods |
| `baselines/DEMD.py` | DEMD, graph-optimisation-style recovery | specification in the manuscript's Methods |
| `baselines/GDR_TS.py` | GDR-TS, learned recovery policy | Li et al. (2025) |
| `baselines/Hybrid_MADDPG_APF.py` | Hybrid-MADDPG | Wang et al. (2025) |
| `baselines/GCN_2017.py` | graph convolutional network baseline | Kipf & Welling (2017); not reported in the manuscript |
| `baselines/GAT.py` | graph attention network baseline | Velickovic et al. (2018); not reported in the manuscript |
| `baselines/dagl/` | ML-DAGL, multi-hop graph-learning recovery | Mou et al. (2022); Lin et al. (2024) |
| `controllers/` | MORPHICA and the relay-limited variant | this work |

## Notes

- **Control-suite data.** `data/control_suites/` holds the per-case rows for the
  matched reruns and diagnostics that accompany the reported experiments. Every
  row records the damage-mask SHA-256 it used, so the evidence can be checked
  against the archived raw logs without re-running anything.
- **Naming.** Module and directory names here follow the release layout; they
  differ from the authors' internal working tree, which is not part of this
  repository.

## Not included

Publisher PDFs, a separate conference manuscript, superseded-version source
files, recovery notes, review material and internal working notes were removed
deliberately. Superseded algorithm attempts that the manuscript does not report
are not part of this repository either.
